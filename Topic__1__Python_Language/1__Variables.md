# Variables in Python

In python simply define a variable and assign a value to it. 

No need to use any keyword

#### Format :

```
_____________ = ______________

variable_name = Value

```

#### Example :

```py
a = 23 # Integer

b = 2.345 # Float

c = "Hello" # String

d = True # Boolean

e = [1, 2, 3] # List
```

# Valid variable names

1. Variables names can contain numbers `[0-9]` and alphabets `[a-z] [A-Z]`
2. Variable names should not start with a number
3. Reserved keywords should not be used as variale names
