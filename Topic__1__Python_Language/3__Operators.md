## Membership Operators

1. `in` and `not in`

```py
# Usage Example
a = [1,2,"Hello"]
b = 2
c = 3
print(b in a)           # Output: True
print(c in a)           # Output: False
print(c not in a)       # Output: True
print("Hello" in a )    # Output: True     
```
